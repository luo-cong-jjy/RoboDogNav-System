# 障碍物最小间距对比测试报告

日期：2026-07-28

## 测试对象

- M20 RViz运动学后端；
- 原生 `m20_scan_planner` / SCAN B样条规划链；
- `0.25 m` SCAN双圆柱半径、前后偏移 `0.18 m`；
- `0.25 + 0.05 = 0.30 m` 独立碰撞保护半径；
- 每层252个障碍物的四套双场景间距档位。

## 静态资产与连通性

| 档位 | 实际最小本体间距 | 障碍物数/层 | `0.30 m`膨胀后任务航段 |
|---:|---:|---:|---:|
| `0.70 m` | `0.702172 m` | 252 | `11/11 PASS` |

测试同时验证PCD/PGM哈希、F2复制关系、任务点未占据，以及所有障碍物对满足各自
最小间距。

## 原生SCAN动态首段

每个档位重新启动一套独立节点图，从相同初始位姿 `(-37, 0, 0.59)` 导航到
F1左下巡检点 `(-36, -16, 0.59)`。目标超时100秒，保持正式速度和安全参数，
不启用可选网格全局路由。

| 档位 | 结果 | 用时 | 最终距离 | A*失败日志 | 碰撞保护停车 |
|---:|---:|---:|---:|---:|---:|
| `0.70 m` | PASS | `32.58 s` | `0.138 m` | 14 | 0 |
| `0.80 m` | PASS | `29.32 s` | `0.129 m` | 0 | 0 |
| `0.90 m` | PASS | `28.52 s` | `0.164 m` | 0 | 0 |
| `1.00 m` | PASS | `30.24 s` | `0.183 m` | 4 | 0 |

四档都在目标容差内成功完成，且首段没有触发独立碰撞保护。`0.70 m` 的局部A*
失败次数明显更多；`0.80 m` 和 `0.90 m` 在本次首段运行中更平顺。`1.00 m`
没有继续变快，是因为间距约束改变了随机障碍物的最终接受布局；这说明只做一个种子
的一次运行不能推导严格单调关系。

## 结论与边界

- 四套场景已可用于RViz人工观察和后续完整任务多轮测试。
- `0.70 m` 仍应定位为极限压力档；静态连通不代表局部规划稳定。
- 当前单次首段结果支持优先继续测试 `0.80 m` 和 `0.90 m`。
- 本报告的动态部分仅覆盖之前发生卡停的首段，不宣称四套11步完整任务已经通过。
